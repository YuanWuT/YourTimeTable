  ```bash
  CRED=$(printf 'protocol=https\nhost=github.com\n\n' | git credential fill)
  GUSER=...; GPASS=...   # 从 CRED 取，绝不打印
  git -c http.sslVerify=false -c http.extraHeader="Host: github.com" \
      -c http.proxy=http://127.0.0.1:65105 \
      push "https://${GUSER}:${GPASS}@140.82.112.3/YuanWuT/YourTimeTable.git" main:main
  ```
  `http.extraHeader` 保证 GitHub 按 Host 路由到仓库；SNI 是 IP 所以临时关证书校验（仅限这一次推送，别写进 remote / 全局配置）。push 后用同样的 URL `fetch +refs/heads/main:refs/remotes/origin/main` 更新本地远端引用，`git status` 才会显示干净。本次远端 `570af4c` 与本地一致，离线 bundle 同步刷新。

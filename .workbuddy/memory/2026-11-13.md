## 周视图批量删除定位修复 + 全量逻辑审计

用户反馈：今天是周五，长按批量删除周一的课，页面却停在周五，要左右滑动才看得到周一。

### 根因

`pages/index/index.js` 的 `recompute()` 每次都把 `scrollIntoId` 设成「今天所在列」（周五 `day-col-4`），而勾选 / 全选 / 长按都触发完整 `recompute()`，于是 `scroll-into-view` 反复把横向 scroll-view 拉回周五；`offset!==0` 时又设成空串，切周后不归位。

### 本次修复

- `index.js` 拆分 `recompute()` 与 `refreshSelection()`：勾选只刷新 `weekColumns`，绝不改写 `scrollIntoId`；`rawColumns` 保存未带 `checked` 的网格源数据。
- 批量模式不自动改写滚动目标；按钮进入从 `day-col-0`（周一）开始，长按进入停在所按课程那天（新增 `data-day`）。`normalScrollTarget()`：本周=今天、其它周=周一；`scrollToId()` 用「先置空再赋值」强制归位（scroll-into-view 值不变时框架不会重滚）。
- 首页与录入网格页都新增「周一~周日」快捷跳转条（`dayTabs` 带当天节数），`scroll-view` 的 `scroll-into-view` 与 `day-col` 的 `id` 配对；grid 页补齐 `id` 与 `scroll-into-view`。
- 批量勾选范围改为「当前视图可见课程」(`visibleCourseIds`)：单周视图下全选不再把双周课一起删；切周 / 切单双周时 `recompute()` 自动清掉不可见的勾选。
- 其它确定性 BUG：月视图按当天真实单双周取课（不再受周视图「全部」影响，并从月视图隐藏无效果的单双周切换条）；缩减节次后把越界 `period_no` 收敛到最后一节标准时间；`replacePeriods` 用字符串比较 id，避免数字/字符串类型不一致把刚更新的行误删；新增节次即时写云端；日历同步前置确认 + 超 40 条截断明确提示（原为静默丢失）；回收站恢复前查重；导入冲突检查覆盖本次导入内部互相重叠；`chooseModels` 在模型不上报 `supportsImages` 时降级重试；批量删除 toast 用云端真实命中数。
